## ⬇️ Télécharger Altis-Of-Life

### **[📥 Accéder au téléchargement de la dernière version](https://github.com/AltisOfLife/HeliosLauncherV4/releases/latest)**

Sélectionnez le fichier correspondant à votre système d'exploitation dans la section **Assets** de la dernière release :

| Système | Fichier à télécharger | Installation |
| --- | --- | --- |
| 🪟 **Windows (64 bits)** | `Altis-Of-Life-setup-.exe` | Lancez le programme d'installation. |
| 🍎 **macOS Intel** | `Altis-Of-Life-setup-x64.dmg` | Ouvrez le DMG et installez l'application. |
| 🍎 **macOS Apple Silicon** | `Altis-Of-Life-setup-arm64.dmg` | Ouvrez le DMG et installez l'application. |
| 🐧 **Linux** | `Altis-Of-Life-setup.AppImage` | Rendez le fichier exécutable puis lancez-le. |

> **Important :** les fichiers `latest.yml`, `latest-mac.yml`, `latest-linux.yml` et `.blockmap` servent au système de mise à jour. Pour une installation manuelle, téléchargez l'installateur adapté à votre système.

## 🛠️ Installation rapide

**Sous Windows**
1. Téléchargez le fichier `.exe` dans les [Releases](https://github.com/AltisOfLife/HeliosLauncherV4/releases/latest).
2. Ouvrez l'installateur et suivez les étapes à l'écran.
3. Lancez **Altis-Of-Life** depuis votre ordinateur.

**Sous macOS**
1. Choisissez le fichier `.dmg` correspondant à votre processeur (Intel `x64` ou Apple Silicon `arm64`).
2. Ouvrez-le et installez le launcher.
3. Ouvrez **Altis-Of-Life**.

**Sous Linux**
1. Téléchargez le fichier `.AppImage`.
2. Autorisez son exécution (par les propriétés du fichier ou avec `chmod +x NomDuFichier.AppImage`).
3. Lancez le fichier.
